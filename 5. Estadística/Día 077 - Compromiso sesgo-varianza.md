# Día 077 — Compromiso sesgo-varianza

## Lección

Marco central para comprender por qué modelos demasiado simples o demasiado flexibles pueden tener peor desempeño predictivo.

## Objetivos

- Definir sesgo y varianza en el contexto predictivo.
- Relacionar complejidad con error de prueba.
- Usar el compromiso sesgo-varianza para razonar sobre modelos.
