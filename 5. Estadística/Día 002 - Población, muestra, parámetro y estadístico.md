# Día 002 — Población, muestra, parámetro y estadístico

## Lección

Estudio de las unidades básicas del razonamiento estadístico: población, muestra, parámetro y estadístico. Se enfatiza por qué casi siempre inferimos características de una población a partir de una muestra.

## Objetivos

- Diferenciar población y muestra.
- Diferenciar parámetro y estadístico.
- Identificar estos elementos en ejemplos reales.

- OpenStax: cap. 1, secc. 1.1–1.2
