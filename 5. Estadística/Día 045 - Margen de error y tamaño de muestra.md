# Día 045 — Margen de error y tamaño de muestra

## Lección

Estudio de cómo nivel de confianza, variabilidad y tamaño muestral afectan la precisión de una estimación.

## Objetivos

- Explicar qué aumenta o reduce el margen de error.
- Relacionar tamaño muestral con precisión.
- Plantear un tamaño de muestra orientado a una precisión objetivo.
