# Día 020 — Análisis exploratorio: variación y covariación

## Lección

Uso sistemático de gráficos y resúmenes para detectar patrones, relaciones, anomalías y preguntas nuevas antes de modelar.

## Objetivos

- Distinguir variación de covariación.
- Explorar relaciones entre variables.
- Formular hipótesis a partir del análisis exploratorio.
