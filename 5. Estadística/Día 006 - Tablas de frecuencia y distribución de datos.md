# Día 006 — Tablas de frecuencia y distribución de datos

## Lección

Organización de datos en frecuencias absolutas, relativas y acumuladas para comprender cómo se distribuyen las observaciones.

## Objetivos

- Construir una tabla de frecuencias.
- Interpretar frecuencias relativas y acumuladas.
- Elegir una representación adecuada según el tipo de variable.
