# Día 036 — Repaso integrado de distribuciones de probabilidad

## Lección

Comparación de binomial, geométrica, hipergeométrica, Poisson, uniforme, exponencial y normal para aprender a reconocer qué modelo corresponde a cada situación.

## Objetivos

- Comparar supuestos de las distribuciones estudiadas.
- Seleccionar un modelo a partir de un enunciado.
- Justificar por qué una distribución es adecuada.

- OpenStax: caps. 4–6
