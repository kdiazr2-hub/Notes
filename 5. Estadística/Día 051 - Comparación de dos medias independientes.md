# Día 051 — Comparación de dos medias independientes

## Lección

Pruebas para evaluar diferencias entre medias de dos poblaciones independientes.

## Objetivos

- Distinguir una comparación independiente de una emparejada.
- Formular hipótesis sobre diferencia de medias.
- Interpretar un contraste de dos medias.
