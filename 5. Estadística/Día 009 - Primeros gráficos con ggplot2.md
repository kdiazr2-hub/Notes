# Día 009 — Primeros gráficos con ggplot2

## Lección

Uso de la gramática básica de gráficos de R para representar datos de manera reproducible. Se conectan variables, estéticas y capas.

## Objetivos

- Comprender la estructura básica de ggplot2.
- Mapear variables a ejes y estéticas.
- Crear gráficos simples a partir de un data frame.
