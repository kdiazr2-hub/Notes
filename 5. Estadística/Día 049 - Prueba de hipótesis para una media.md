# Día 049 — Prueba de hipótesis para una media

## Lección

Aplicación completa del procedimiento de contraste para evaluar una afirmación sobre una media poblacional.

## Objetivos

- Plantear H0 y Ha para una media.
- Elegir la distribución de referencia.
- Interpretar estadístico, valor p y conclusión.
