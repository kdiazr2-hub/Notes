# Día 018 — Crear variables y resumir grupos con dplyr

## Lección

Construcción de variables derivadas y estadísticas por grupo mediante mutate(), summarize() y operaciones agrupadas.

## Objetivos

- Crear variables con mutate().
- Calcular resúmenes con summarize().
- Comparar subgrupos con group_by().
