# Día 062 — Regresión lineal simple

## Lección

Construcción de una recta para describir la relación media entre un predictor cuantitativo y una respuesta cuantitativa.

## Objetivos

- Interpretar intercepto y pendiente.
- Comprender la ecuación de regresión.
- Usar una recta para describir una relación lineal.
