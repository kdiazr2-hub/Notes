# Día 040 — Error estándar y precisión de una estimación

## Lección

Interpretación del error estándar como medida de la variabilidad de un estimador entre muestras repetidas.

## Objetivos

- Distinguir desviación estándar de error estándar.
- Explicar cómo cambia con el tamaño muestral.
- Conectar error estándar con precisión.

## Lectura base

- OpenStax: caps. 7–8
