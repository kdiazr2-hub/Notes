# Día 079 — Regresión logística

## Lección

Modelo para estimar probabilidades de una respuesta categórica binaria usando una función logística.

## Objetivos

- Comprender la forma del modelo logístico.
- Interpretar probabilidades predichas.
- Distinguir regresión logística de regresión lineal.
