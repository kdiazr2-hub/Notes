# Día 025 — Diagramas de árbol y diagramas de Venn

## Lección

Representaciones visuales para descomponer procesos probabilísticos y relaciones entre eventos.

## Objetivos

- Usar árboles para probabilidades secuenciales.
- Usar diagramas de Venn para uniones e intersecciones.
- Elegir la representación más útil para un problema.
