# Día 019 — Datos ordenados, datos faltantes y tidyr

## Lección

Principios de tidy data: una variable por columna y una observación por fila. Se introduce el tratamiento estructural de datos faltantes.

## Objetivos

- Reconocer datos tidy y no tidy.
- Reestructurar conceptualmente un conjunto de datos.
- Distinguir valores faltantes explícitos e implícitos.

## Lectura base

- R4DS: cap. 9, Tidy Data y Missing Values
