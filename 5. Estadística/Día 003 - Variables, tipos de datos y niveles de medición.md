# Día 003 — Variables, tipos de datos y niveles de medición

## Lección

Clasificación de variables y datos según su naturaleza y nivel de medición. Esto determina qué resúmenes, gráficos y métodos estadísticos son apropiados.

## Objetivos

- Distinguir variables cualitativas y cuantitativas.
- Reconocer variables discretas y continuas.
- Identificar niveles de medición.
