# Día 026 — Variables aleatorias discretas y función de probabilidad

## Lección

Paso desde eventos aislados a variables aleatorias que asignan valores numéricos a resultados de un experimento.

## Objetivos

- Definir una variable aleatoria discreta.
- Interpretar una función de probabilidad.
- Verificar que una distribución discreta sea válida.
