# Día 033 — Distribución normal

## Lección

Estudio de la distribución normal como modelo central para muchas variables y como base de múltiples métodos inferenciales.

## Objetivos

- Reconocer propiedades de una normal.
- Interpretar media y desviación estándar en una normal.
- Identificar cuándo un modelo normal es razonable.

## Lectura base

- OpenStax: cap. 6, secc. 6.1–6.2
