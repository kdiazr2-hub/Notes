# Día 057 — Homogeneidad y prueba de una varianza

## Lección

Comparación de distribuciones categóricas entre poblaciones y revisión del uso de chi-cuadrado para una varianza.

## Objetivos

- Distinguir independencia de homogeneidad.
- Reconocer cuándo comparar distribuciones categóricas.
- Comprender el uso de chi-cuadrado en una prueba de varianza.

## Lectura base

- OpenStax: cap. 11, secc. 11.4–11.6
