# Día 095 — Análisis de componentes principales

## Lección

Método no supervisado para representar datos de alta dimensión mediante nuevas direcciones que concentran la variabilidad.

## Objetivos

- Comprender qué es un componente principal.
- Interpretar varianza explicada.
- Reconocer usos de PCA para visualización y reducción de dimensión.

- ISLR: cap. 10, secc. 10.2
