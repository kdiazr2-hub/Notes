# Cómo usar esta carpeta en Obsidian

1. Descomprime la carpeta dentro de tu Vault.
2. Abre `000 - Índice del plan.md`.
3. Estudia un archivo por día, en orden.
4. Cuando completes una lección, puedes escribir tus propias notas debajo del contenido existente.

Los archivos están numerados para mantener el orden automáticamente.
