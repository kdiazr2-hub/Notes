# Día 053 — Comparación de dos proporciones

## Lección

Contraste de diferencias entre proporciones de dos poblaciones independientes.

## Objetivos

- Plantear hipótesis para dos proporciones.
- Calcular e interpretar una diferencia de proporciones.
- Distinguir relevancia estadística de relevancia práctica.

## Lectura base

- OpenStax: cap. 10, secc. 10.3 y 10.5
