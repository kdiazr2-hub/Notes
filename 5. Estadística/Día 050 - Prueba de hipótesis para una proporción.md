# Día 050 — Prueba de hipótesis para una proporción

## Lección

Contraste de una afirmación sobre una proporción poblacional a partir de datos muestrales.

## Objetivos

- Plantear hipótesis sobre una proporción.
- Verificar condiciones del procedimiento.
- Interpretar el resultado en contexto.
