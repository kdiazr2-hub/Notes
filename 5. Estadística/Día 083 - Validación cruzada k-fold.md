# Día 083 — Validación cruzada k-fold

## Lección

Evaluación de modelos mediante partición repetida de los datos en k bloques para obtener una estimación más estable del error de generalización.

## Objetivos

- Describir k-fold cross-validation.
- Explicar por qué reduce dependencia de una sola partición.
- Usar CV para comparar complejidad de modelos.

- ISLR: cap. 5, secc. 5.1.3–5.1.5
