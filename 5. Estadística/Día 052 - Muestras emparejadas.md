# Día 052 — Muestras emparejadas

## Lección

Análisis de datos donde cada observación de un grupo tiene una correspondencia natural con otra, como medidas antes-después.

## Objetivos

- Reconocer un diseño emparejado.
- Transformar el problema en diferencias pareadas.
- Interpretar una prueba para la media de las diferencias.
