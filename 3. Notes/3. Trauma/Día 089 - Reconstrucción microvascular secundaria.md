# Día 089 — Reconstrucción microvascular secundaria

## Lección

Uso de colgajos libres para defectos complejos con pérdida de hueso y tejidos blandos.

## Objetivos

- Reconocer cuándo se necesita tejido vascularizado.
- Distinguir objetivos óseos y de cobertura.
- Relacionar elección del colgajo con componentes del defecto.

- FTS: 3.13 Secondary Microvascular Reconstruction
