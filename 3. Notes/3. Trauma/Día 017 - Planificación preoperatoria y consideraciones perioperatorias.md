# Día 017 — Planificación preoperatoria y consideraciones perioperatorias

## Lección

Organización del tratamiento a partir de diagnóstico, estado general, prioridades reconstructivas y secuencia quirúrgica.

## Objetivos

- Definir objetivos preoperatorios claros.
- Reconocer factores sistémicos que condicionan el plan.
- Construir una secuencia de problemas antes de una secuencia de procedimientos.
