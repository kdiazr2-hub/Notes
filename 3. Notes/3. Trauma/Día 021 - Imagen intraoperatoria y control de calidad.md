# Día 021 — Imagen intraoperatoria y control de calidad

## Lección

Uso de navegación, imagen 3D e integración de datos para verificar reducción y posición de implantes.

## Objetivos

- Explicar el objetivo del control de calidad intraoperatorio.
- Reconocer usos de navegación e imagen 3D.
- Relacionar verificación intraoperatoria con prevención de deformidad residual.
