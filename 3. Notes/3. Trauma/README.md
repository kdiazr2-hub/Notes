# Cómo usar este plan en Obsidian

1. Descomprime esta carpeta dentro de tu Vault.
2. Abre `000 - Índice del plan.md`.
3. Estudia los días en orden.
4. Cada nota ya contiene el tema, una descripción breve, objetivos y las secciones sugeridas de lectura.
5. Debajo de esas secciones puedes escribir tus propias notas, esquemas, preguntas y perlas clínicas.

## Libros base

- *Facial Trauma Surgery: From Primary Repair to Reconstruction*.
- *Principles of Internal Fixation of the Craniomaxillofacial Skeleton: Trauma and Orthognathic Surgery*.

El plan es educativo y está diseñado para organizar la lectura; las decisiones clínicas y técnicas deben ajustarse a supervisión, protocolos locales y evidencia actual.
