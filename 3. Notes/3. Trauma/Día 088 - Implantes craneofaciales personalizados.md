# Día 088 — Implantes craneofaciales personalizados

## Lección

Uso de CAD/CAM e implantes específicos del paciente para restaurar contorno y volumen en secuelas complejas.

## Objetivos

- Explicar el flujo conceptual CAD/CAM.
- Reconocer ventajas y limitaciones de implantes personalizados.
- Relacionar diseño del implante con anatomía residual.
