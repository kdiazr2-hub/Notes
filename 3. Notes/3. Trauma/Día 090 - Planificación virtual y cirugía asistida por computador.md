# Día 090 — Planificación virtual y cirugía asistida por computador

## Lección

Aplicación de planificación virtual, modelos, guías, navegación y transferencia del plan a la reconstrucción.

## Objetivos

- Describir un flujo básico de planificación virtual.
- Reconocer diferencias entre planificación primaria y secundaria.
- Identificar fuentes potenciales de error entre plan y ejecución.

## Lectura base

- FTS: 3.14 Virtual Surgical Planning
