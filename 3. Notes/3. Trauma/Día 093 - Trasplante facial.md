# Día 093 — Trasplante facial

## Lección

Panorama de las indicaciones, clasificación, complejidad reconstructiva y seguimiento de trasplante facial.

## Objetivos

- Reconocer el tipo de defecto que puede llevar a considerar trasplante.
- Comprender la complejidad multidisciplinaria del procedimiento.
- Identificar riesgos agudos y crónicos generales.

## Lectura base

- FTS: 3.17 Facial Transplantation
