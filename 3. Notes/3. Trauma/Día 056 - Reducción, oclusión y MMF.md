# Día 056 — Reducción, oclusión y MMF

## Lección

Principios de control oclusal y fijación maxilomandibular como herramientas para restaurar la relación maxilomandibular.

## Objetivos

- Explicar el papel de la oclusión como referencia.
- Reconocer técnicas generales de MMF.
- Distinguir MMF como herramienta de reducción, estabilización o ambas.
