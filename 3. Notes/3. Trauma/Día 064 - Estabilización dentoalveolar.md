# Día 064 — Estabilización dentoalveolar

## Lección

Principios de reposicionamiento y estabilización de dientes o segmentos alveolares traumatizados.

## Objetivos

- Explicar el objetivo de una férula dentoalveolar.
- Distinguir estabilidad necesaria de rigidez excesiva de forma conceptual.
- Relacionar seguimiento con complicaciones pulpares y periodontales.
